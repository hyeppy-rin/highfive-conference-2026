원티드 하이파이브 2026 'Makers Day'에 참석하지 못한 팀원들에게 공유할
정적 HTML 페이지를 만들어줘.

────────────────────────────────────────
## 🎯 목적
컨퍼런스에 참석하지 못한 팀원들이
(1) 첫 화면에서 어떤 세션들이 있었는지 한눈에 파악하고
(2) 관심 있는 세션만 골라 깊게 읽을 수 있도록 하는 것.

────────────────────────────────────────
## 📌 컨퍼런스 정보
- 행사명: 원티드 하이파이브 2026 (Wanted High Five 2026)
- 슬로건: 확장의 시대 (The Age of Expansion)
- 일시: 2026년 5월 13일 (Makers Day)
- 장소: COEX 그랜드볼룸 & 오디토리움
- 트랙: UX Design / Tech / PO·PM / Growth (4개)
- 부대 프로그램: 런치 패널 토크

────────────────────────────────────────
## 📄 콘텐츠 소스 (Single Source of Truth)
세션 정리본은 `[세션정리.md]` 파일에 있어.

⚠️ 중요 원칙:
- MD 파일에 있는 **모든 내용**을 HTML에 빠짐없이 옮길 것
- MD에 없는 정보를 임의로 추가/창작하지 말 것
- MD에 없는 세션을 만들어내지 말 것
- 정보를 요약하거나 축약하지 말 것 (디자인 구조만 입히는 것)
- 단, MD의 마크다운 문법(##, **, -, > 등)은 적절한 HTML 시맨틱 태그로 변환

  2. 그 바로 아래에 각 세션 + 런치 패널 토크로 진입하는 버튼 그리드

────────────────────────────────────────
## 🏗 페이지 구조

### [1] Hero (첫 화면, 스크롤 없이 보이는 영역)
- 컨퍼런스명: "원티드 하이파이브 2026"
- 부제: "확장의 시대 · Makers Day"
- 일시/장소 한 줄 메타
- 👉 그 바로 아래에 **세션 진입 버튼 그리드**
  - 각 버튼: 트랙 라벨(UX/Tech/PO·PM/Growth) + 세션 제목 + 연사
  - 런치 패널 토크 버튼도 동일한 그리드에 포함
  - 클릭 시 해당 세션 상세 섹션으로 부드럽게 스크롤 이동 (smooth scroll)
  - 트랙별로 색상 또는 라벨로 구분

### [2] 세션 상세 영역 (스크롤 후 노출)
MD에 작성된 순서대로 각 세션을 풀 콘텐츠로 노출.
- 세션별 앵커 ID 부여 (#session-1, #session-2 ...)
- 상단으로 돌아가기 버튼(floating)
- 각 세션 사이 충분한 여백으로 가독성 확보

### [3] Footer
- 컨퍼런스 공식 페이지 링크
- 작성자/공유일 (옵션)

────────────────────────────────────────
## 🛠 기술 제약
- **단일 HTML 파일** (CSS, JS 모두 인라인)
- 외부 라이브러리/CDN 의존성 없음 (사내 어디서든 로컬로 열려야 함)
- 한글 웹폰트는 Pretendard CDN 1개만 허용 (없으면 system-ui fallback)
- 반응형: 데스크톱(1280px+) / 태블릿 / 모바일 모두 자연스럽게
- 다크모드 자동 대응 (`prefers-color-scheme`)
- 접근성: 시맨틱 태그(<header>, <main>, <section>, <nav>), 키보드 포커스 가능

────────────────────────────────────────
## 🎨 디자인 톤
- 깔끔하고 정보 위계가 명확한 레이아웃 (토스 TMC 스타일)
- 여백 넉넉하게, 본문 가독성 우선
- 한글 타이포: 제목 굵게/넉넉하게, 본문 line-height 1.7 이상
- 트랙별 컬러 토큰 4개 (UX, Tech, PO·PM, Growth) — 차분한 채도
- 인용/하이라이트/액션 아이템은 시각적으로 구분 (인용블록, 박스, 아이콘)
- 애니메이션은 절제 (hover 트랜지션, smooth scroll 정도만)

## 🚦 작업 순서
1. 먼저 `[2026_HIGH_FIVE_완전세션정리.md]` 파일을 읽어서 어떤 세션들이 있는지 목록만 출력해줘
2. 내가 "진행" 이라고 답하면, HTML 페이지 outline(섹션 구조)을 보여줘
3. 내가 "OK" 라고 답하면, 그때 단일 HTML 파일을 생성
4. 완성 후 브라우저에서 열어볼 수 있게 파일 경로를 알려줘
